# Product Admin Dashboard

A responsive product administration dashboard built with Next.js, React, Tailwind CSS, Axios and the DummyJSON API.

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Axios
- DummyJSON API

## Features

- User login
- Protected product routes
- Logout
- Product listing
- Responsive desktop table
- Responsive mobile cards
- Pagination
- Page size selection
- Product search
- Debounced search
- Request cancellation for stale searches
- Category filtering
- Product sorting
- URL-based page/search/filter/sort state
- Product details
- Product reviews
- Add product
- Edit product
- Delete product
- Delete confirmation
- Loading states
- Empty states
- Error states
- Retry functionality
- Invalid URL parameter handling
